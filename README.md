# Cosmetics Management System

화장품 온라인 판매 및 유통 관리 시스템

## 기술 스택
- Frontend: Flutter (Riverpod, MVVM)
- Backend: FastAPI
- Database: MySQL
- Platform: Android

## 프로젝트 구조
- backend: FastAPI 서버
- frontend: Flutter 애플리케이션
- database: MySQL SQL 파일

## 팀원 역할
- A: 고객 (스마트폰)
- B: 본사 직원 (태블릿)
- C: 본사 관리자 및 배송업체 담당자 (태블릿)

## 데이터베이스
- Database Name: cosmetics_management
- MySQL 8.0.16 이상
